# Description

The function ft_printf reproduce the behaviour of the function printf from the library <stdio.h>.
The available formats are :

- %c : single characters
- %s : string of characters
- %p : adress of a pointer
- %d : decimal base 10 number
- %i : integer base 10 number
- %u : unsigned decimal base 10 number
- %x : number in hexadecimal in lowercase format
- %X : number in hexadecimal in uppercase format
- %% : print a % character
