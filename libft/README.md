# Description

Libft is an accumulation of usefull function for that we can use for the rest of our projects in C.
It contains function from the standard library LIBC, soem other usefull fonction and some related to linked lists.

## LIBC Functions

|isalpha|   ->  Return 1 if the input is a letter, otherwise 0.
|isdigit|   ->  Return 1 if the input is a number, otherwise 0.
|isalnum|   ->  Return 1 if the input is a letter or a number, otherwise 0.
|isascii|   ->  Return 1 if the input is part of the ascii table, otherwise 0.
|isprint|   ->  Return 1 if the input is a printable character, otherwise 0.
|strlen |   ->  Return the lenght of a string.
|memset |   ->  Set n bytes of a memory space to a certain character.
|bzero  |   ->  Set n bytes of a memory space to 0.
|memcpy |   ->  Copy a certain number of bytes from a memory space to an other (doesn't manage overlaping).
|memmove|   ->  Copy a certain number of bytes from a memory space to an other (manage overlaping).
|strlcpy|   ->  Copy a string to an other for a certain amount of characters, without exceeding the destination.
|strlcat|   ->  Concatenate a string with an other and return the length of the string it tried to create.
|toupper|   ->  Convert lower case to upper case.
|tolower|   ->  Convert upper case to lower case.
|strchr |   ->  Search for the first appearence of a character in a string and return a pointer to it.
|strrchr|   ->  Search for the last appearence of a character in a string and return a pointer to it.
|strncmp|   ->  Compare two strings for n characters and return 0 / negative / positive number.
|memchr |   ->  Search for the first appearence of an int in amemory space and return a pointer to it.
|memcmp |   ->  Compare two memory spaces for n bytes and return 0 / negative / positive number.
|strnstr|   ->  Search for a string in an other in a certain limit of characters and return a pointer to it.
|atoi   |   ->  Convert a number formated in characters to the same one in integers.
|calloc |   ->  Allocate memory space using malloc and prevent esceeding capacity.
|strdup |   ->  Duplicate a string in a new memory space.
